Política de Privacidade

Versão v1-2026-09 · Última atualização: setembro de 2026

Aviso: este é um rascunho descrevendo, de forma honesta, o que o sistema koren realmente coleta e faz com os dados hoje. Ainda não foi revisado por um advogado e não deve ser tratado como o documento jurídico definitivo da empresa antes dessa revisão.

1. Quem trata os seus dados

O koren é um sistema operado pela Korentech para gestão de motoristas parceiros, empresas administradoras e corridas particulares. Ao se cadastrar como motorista, seus dados pessoais são tratados pela Korentech e, quando você se cadastra através do link de convite de uma empresa parceira, também ficam visíveis para o administrador dessa empresa.

2. Quais dados coletamos

  • Identificação: nome completo, CPF, e-mail, telefone/WhatsApp, endereço residencial.
  • Documentos: fotos da CNH (frente e verso) e do CRLV do veículo.
  • Veículo: placa, modelo, ano, cor, tipo de combustível, foto do automóvel.
  • Acesso: senha (armazenada com hash criptográfico, nunca em texto puro).
  • Localização: sua localização aproximada é usada para centralizar o mapa do Cockpit — não é armazenada no banco de dados, só usada em tempo real na tela.
  • Atividade: corridas registradas (incluindo nome e telefone de passageiros que você cadastra), despesas, tarifas praticadas, status online/offline.
  • Dados de quem solicita corrida pelo seu Link Direto: nome e WhatsApp de clientes que preenchem o formulário público de solicitação — esses dados vão direto pro seu WhatsApp via mensagem, não ficam armazenados no banco do koren.

3. Para que usamos esses dados

  • Criar e autenticar sua conta de motorista;
  • Permitir que você registre e acompanhe corridas, despesas e tarifas;
  • Permitir que a empresa administradora (quando aplicável) gerencie os motoristas vinculados a ela;
  • Gerar o seu Link Direto de Corrida Particular, usado por passageiros pra te contatar;
  • Enviar uma mensagem de boas-vindas pelo WhatsApp quando você se cadastra.

4. Com quem compartilhamos

Não vendemos nem compartilhamos seus dados com terceiros para fins de publicidade. Compartilhamos dados apenas nestes casos:

  • Empresa administradora: se você se cadastrou via link de convite de um admin, ele vê seu nome, telefone, e-mail, status e avaliação — nunca CPF, endereço ou fotos de documentos.
  • Evolution API (WhatsApp): usamos esse serviço, hospedado em infraestrutura própria da Korentech, só para enviar a mensagem de boas-vindas. Seu número de telefone é compartilhado com esse serviço unicamente para esse fim.

5. Como protegemos seus dados

Senhas são armazenadas com hash criptográfico (scrypt), nunca em texto simples. O banco de dados usa políticas de segurança em nível de linha (Row-Level Security): tecnicamente, nenhum motorista consegue acessar dados de outro motorista pela plataforma, mesmo em caso de falha de programação nas telas do aplicativo.

6. Por quanto tempo guardamos

Guardamos seus dados enquanto sua conta estiver ativa. Se você excluir sua conta, seus dados de cadastro, veículos, despesas, corridas e tarifas são apagados permanentemente do banco de dados.

7. Seus direitos

Nos termos da Lei Geral de Proteção de Dados (Lei 13.709/2018), você pode, direto pela tela de Perfil do app:

  • Acessar e baixar uma cópia completa dos seus dados (botão "Baixar meus dados");
  • Corrigir dados incorretos, editando seu cadastro;
  • Excluir sua conta e todos os dados vinculados a ela (botão "Excluir minha conta");
  • Revogar seu consentimento a qualquer momento, o que na prática significa excluir sua conta, já que o cadastro depende desse consentimento.

8. Contato

Dúvidas sobre esta política ou sobre seus dados podem ser enviadas para privacidade@korentech.com.br.
